一、需求背景

直播间首次到访的初高中学生，在听完一段作文讲解后，手上往往正放着一篇刚写完或正在写的作文。他们知道「要多练」，但不知道手上这一篇具体差在哪、下一步该练什么；替孩子操作的家长同样只能凭感觉判断要不要继续跟学。

对用户来说，拿不到针对自己这篇作文的判断，学习就停在「听懂了但不会用」；对业务来说，讲解结束后缺少一个轻量的承接动作，用户直接离开，学习意图无法沉淀，也没有任何可追踪的转化路径。

二、需求目标

让学生在一次轻量体验里就拿到「自己这篇作文」的诊断结论和明确的下一步动作，从而愿意继续试听或练习。

用户结果衡量指标统计口径预期方向目标值
学生愿意把写作情况填完并交出作文测评提交完成率诊断提交成功数 / 进入测评封面数↑待基线确认
交出的作文能拿到结果，不白等一次报告到达率诊断报告成功曝光数 / 诊断提交数↑待基线确认
拿到的结论与自己这篇作文相关，而不是通用模板修改示例贴合率抽样人工评估「修改示例引用了本次作文原句」的通过数 / 抽样数↑待基线确认
看完诊断愿意继续行动推荐内容点击率课程或练习卡片点击数 / 报告曝光数↑待基线确认

三、需求概述（功能清单）

本期范围
  • 测评封面、微信授权与手机号绑定、测评启动
  • 与诊断直接相关的写作情况采集：年级、作文水平自评（必填）、期望提升方向（选填）
  • 上传前选择诊断学科（语文 / 英语）；英语需进一步选择写作类型（应用文 / 读后续写），再完成题目图与正文图的拍摄 / 相册选择、预览与本地校验
  • AI 诊断的处理中、成功、失败三类反馈
  • 诊断报告：称号、能力画像、优先提升建议、AI 修改示例
  • 个性化推荐：从固定内容库中给出试听课入口与配套作文练习入口
  • 试听课程播放、章节目录与课后练习入口
  • 从封面到试听课的五步链路关键埋点
  • AI 诊断能力、AI 批改能力的接入与联调

3.1 链路准入与身份要求

环节要求说明
打开测评封面无需登录即可打开直播间挂载入口、活动落地页与外部链接均可直接打开
微信授权与手机号绑定在扫码后的第一个页面、点击「开始测评」之前完成未完成授权与绑定不予放行，不进入写作情况页

3.2 写作材料通用约束

维度取值说明
诊断学科语文 / 英语，单选必填未选学科时不展示材料上传区；点击诊断按钮提示「请先选择学科」
英语写作类型应用文 / 读后续写，单选必填仅选择英语后出现；未选类型时不展示材料上传区，点击诊断按钮提示「请选择英语写作类型」
支持格式JPG、PNG其他格式不予受理，不做静默转码
作文题目图数量1 张再次选择即替换原图
作文正文图数量2 张按图张数计，不额外限制页数；再次选择即替换原图
单张大小上限由前端决定产品侧不下发统一上限，由前端按压缩策略实现，超限时按前端提示处理
图片留存与使用留存与删除由前端决定；不用于模型训练产品侧不下发统一留存时长；本次诊断上传的作文图片与识别文本均不进入模型训练

3.3 诊断与推荐通用口径

维度取值说明
能力维度审题立意 / 结构论证 / 语言表达 / 素材运用四个维度固定；本版为暂定口径，教研侧仍在调整，调整后以新版 PRD 为准
成绩呈现只展示程度环，不出现数字分数文案用「较突出 / 较稳定 / 待提升」定性表达，避免制造考试成绩感
优先提升项有且只有一个由诊断维度与作文证据综合决定，不能简单等同于最低分项；判定规则仍待教研与算法确认
推荐内容来源固定内容库课程与练习存在一个固定的后台内容库，由 AI 按优先提升项判断返回库中哪一条，不支持运营配置
推荐匹配须与优先提升项、作文类型、年级一致多候选排序规则与兜底策略待确认

3.4 页面状态保留

状态对象保留范围说明
写作情况已选内容保留页面刷新、中途退出后重新进入，年级、自评水平与提升方向不重填
学科与英语写作类型保留页面刷新、中途退出后重新进入，保留已选学科；英语场景同时保留应用文 / 读后续写选择

诊断结果与报告保留报告生成后刷新或退出重进，仍可从报告页继续，不重复发起诊断
试听播放进度保留播放中退出后重新进入，保留上次播放进度与高亮章节

P03 上传材料

打开可点击原型
【页面元素】

1、顶部：返回按钮与品牌名「智卷星辰」，不展示拍摄帮助入口

2、三步进度条「1 了解你 / 2 上传材料 / 3 获得建议」，当前高亮第 2 步

3、必填项「选择学科」：语文、英语，两个单选按钮

4、选择英语后展开必填项「选择英语写作类型」：应用文、读后续写；选择语文时不展示该项

5、学科上下文选择完整后展示模块标题「上传写作材料」与两张上传卡

6、上传卡一「MATERIAL 01 拍作文题目」，带「必传」标记，说明「拍清题干、材料和写作要求」

7、上传卡二「MATERIAL 02 拍作文正文」，带「必传」标记，说明「拍清标题与全文，多页可连续选择」

8、材料添加成功后，卡片内展示纸张式预览与扫描动效

9、拍照提示行「题目与正文需对应」「图片仅用于本次诊断」

10、主按钮「开始 AI 诊断」；页面不展示隐私声明行

【交互说明】

1、初始进入页面 → 上传区隐藏，先选择语文或英语

2、选择语文 → 直接展示题目与正文上传区

3、选择英语 → 展开「应用文 / 读后续写」必选项；选择任一类型后展示题目与正文上传区

4、切换学科 → 清空原英语写作类型选择，并按新学科重新执行展示条件；已选材料是否清空由研发按数据隔离方案实现，但不得将不同学科材料提交到同一次诊断

5、未选学科点击「开始 AI 诊断」→ 拦截并提示「请先选择学科」；已选英语但未选类型 → 拦截并提示「请选择英语写作类型」

6、点击任一上传卡 → 调起系统拍照或相册选择器

7、作文题目图选择成功 → 该卡切换为已添加样式并展示预览，不影响作文正文卡

8、作文正文图选择成功 → 该卡切换为已添加样式并展示预览，支持一次连续选择多张

9、点击「开始 AI 诊断」时两类材料均未添加 → 拦截提交，提示「请先上传作文题目」

10、题目图已有、正文图缺失 → 拦截提交，提示「请再上传作文正文」

11、学科上下文与两类材料齐全后点击 → 按钮进入禁用态，文案变为「正在生成你的诊断…」，进度条切到「3 获得建议」

12、诊断成功返回 → 进入诊断报告页；诊断未成功 → 保留学科上下文与两类材料并允许重新发起

13、诊断处理耗时较长 → 持续展示「正在生成你的诊断…」，不设超时阈值、不自动判失败、不误报失败

14、点击左上角返回 → 回到写作情况页；页面刷新或中途退出后重新进入本页时，保留学科、英语写作类型（如有）与两类已选材料

【功能逻辑】

1、语文场景须满足「已选语文 + 两类材料齐全」；英语场景须满足「已选英语 + 已选写作类型 + 两类材料齐全」，才允许发起诊断

【数据与内容规则】

1、图片格式、数量与大小约束见需求概述的写作材料通用约束规则表

2、学科与英语写作类型作为诊断上下文随材料一并提交；题目与正文是否对应由诊断环节判断，本页不做内容校验

3、图片留存与删除策略由前端实现决定，产品侧不下发统一留存时长

4、本次诊断上传的作文图片与识别文本均不用于任何模型训练

【边界说明】

1、取消系统选择器 → 停留在本页，已选材料不变

2、选择不支持的格式或超出前端设定的大小上限 → 该卡不写入，提示支持范围并保持未添加状态

3、诊断处理中重复点击按钮 → 按钮已禁用，仅接受首次提交，不产生第二次诊断

4、页面刷新或中途退出后重新进入 → 已选材料保留，不要求重新拍摄

【页面元素】

1、顶部：返回按钮、标题「我的成长档案」、状态「AI 作文诊断 · 已生成」，本页不设分享入口

4、推荐区主标题「专属提升课程」

5、课程卡：类型「专属提升课 · 学会把观点讲透」、课程名（原型为「议论文：把观点讲透的 3 个方法」）、封面播放按钮与右侧箭头

6、练习卡：类型「配套作文练习 · 学完立即巩固」、练习名（原型为《选择与成长》议论文写作）与右侧箭头

【交互说明】

1、诊断成功后自动进入本页，页面滚动位置重置到顶部

2、点击课程卡封面播放按钮或右侧箭头 → 进入试听课程页

3、点击练习卡右侧箭头 → 打开对应专项练习，当前原型为轻提示演示，正式练习页不在本期范围

4、点击返回 → 回到材料上传页，保留已选材料与本次诊断结果

【数据与内容规则】

1、称号由诊断结果映射生成，须积极、具体，不对学生作人格或能力定性；原型中的「潜力表达者」仅为演示样例

2、正式诊断正文使用业务侧提供的现成文本；原型只做区域与篇幅占位，不定义或改写实际报告内容

3、推荐区展示的课程与练习取自管理后台，由固定规则判断什么条件下推荐哪些课程与试题，文件待提供

4、原型中的课程名与练习名均为演示样例，不是固定返回值

写作能力区间称号报告文案
0%–49%写作启航者已经迈出表达的第一步，接下来重点练习审题、句子表达与内容完整性。
50%–59%表达筑基者能够完成基本写作任务，继续加强结构组织，文章会更加清楚完整。
60%–69%结构进阶者已具备较清晰的写作框架，进一步丰富论证与细节，表达会更有层次。
70%–84%深度表达者能够准确表达观点或主题，兼顾结构与语言，正在形成较成熟的写作能力。
85%–100%卓越创作者立意、结构与语言表现突出，能够写出具有思考深度和感染力的文章。
【边界说明】

1、正式诊断正文文本缺失 → 不展示空白报告卡，视为报告生成失败并进入既有失败处理

2、诊断结果置信度不足 → 不展示强结论，改为提示样本不足并建议重新提交

3、修改建议命中敏感、危险或个人信息内容 → 按内容安全策略隐藏或改写后再展示

4、课程下架或练习无匹配内容 → 不展示失效入口，改为通用提升建议或兜底内容

5、本页无分享入口 → 报告不生成对外可访问的链接，无需处理分享访问权限与脱敏
