# PM数据分析报告工作流

## 输入与范围

复用 `[需求名]/`，输出 `数据分析/[需求名]-数据分析.html`。可接受原始 CSV/Excel、汇总表、看板截图或用户转述。
先确认数据来源、统计周期、时区和分析问题；截图或转述只支持其覆盖的汇总分析，不能反推不存在的明细、完整漏斗或实验结果。
读取相关 PRD 已定义的成功指标和事件口径；冲突时说明差异并确认。明确区分真实数据、转述和用户授权的演示数据，模拟报告全程标记。

## 先建立指标字典

每个实际使用的指标写明：业务含义、分子、分母、单位、去重对象、纳入/排除条件、观察窗口、事件顺序、数据字段、比较基准与来源。
分母为零显示“暂无可计算样本”；缺少必要字段时标记“无法计算”，不能以零代替。
同比、环比和百分点变化分别说明。没有经确认的目标值，不自行制造目标或达标结论。

## 数据质量检查

- 保留原始数据，在副本上处理；记录重复、缺失、非法值、时间异常和排除数量。
- 检查用户/任务/订单等统计单位是否混用，事件是否重复、是否乱序、观察窗是否完整。
- 识别版本、人群、渠道或曝光口径变化，避免不具可比性的样本直接比较。
- 有成熟观察窗的留存和转化只计算已满足观察时长的队列。
- 对可复算的数据保留计算脚本或公式及结果明细，图表数字来自同一份结果。

## 分析与结论

1. 展示关键指标、有效样本和可比较基准。
2. 仅在数据能建立连续路径时绘制漏斗；说明按用户、任务还是事件计数，并披露未匹配和缺失事件。
3. 分群维度按问题和字段选择，不任意扩大切片。小样本注明不确定性。
4. 描述性变化、相关关系和因果结论分开。归因写成有证据的解释或待验证假设，配可执行验证动作。
5. A/B 分析需确认分配单位、实验分组、曝光、观察期、主要指标、样本规模与不确定性，检查样本比例异常和组间污染。条件不足时只做描述性比较，不能宣布实验胜出。
6. 建议数量按证据确定，注明预期影响、依据、优先级和后续验证指标。

## 输出与自查

HTML 包含范围与来源、质量报告、指标字典、样本量、趋势/漏斗等适用图表、结论与限制、行动项。
报告与数据表使用同一结果；抽查分子分母和汇总勾稽；提供公式或计算方式供复算。
演示数据不能作为上线收益；未执行的采集、实验或业务动作标记为建议。
