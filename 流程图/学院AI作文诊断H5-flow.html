图 2 · 诊断任务状态流转

stateDiagram-v2
    direction LR
    [*] --> Idle
    Idle --> ContextPartial : 未选学科 / 英语未选写作类型
    ContextPartial --> MaterialPending : 学科上下文完整
    MaterialPending --> Partial : 仅选择一类材料
    Partial --> Ready : 学科上下文与两类材料齐全
    Ready --> Running : 点击「开始 AI 诊断」
    Running --> Done : 识别与诊断成功
    Running --> Failed : 识别失败 / 服务异常
    Failed --> Running : 重新提交
    Done --> [*]
    note right of Running
      按钮进入禁用态，不接受重复提交
      不设超时阈值，耗时较长时持续展示处理中
    end note
    note right of Failed
      保留已选材料，提供重新诊断
    end note

状态对照：Idle＝初始　ContextPartial＝学科上下文不全　MaterialPending＝待上传　Partial＝材料不全　Ready＝可提交　Running＝诊断中　Done＝已生成报告　Failed＝诊断失败
