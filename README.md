## 范围

这是需求与前端交互演示；上传、AI 诊断及视频播放不代表已接入生产服务。文档含历史待确认事项，以正文标注为准。

本归档移除了指向原电脑的保存服务配置及其导出客户端引用；保留正文和交互演示，本机“保存并通知 AI”等功能不包含在此归档中。未收录内部沟通记录、导出清单及机器配置。
